## About this entry

Everyone has sat through the meeting that should have been an email,
so the joke needs no setup, only a fresh turn. This entry concedes
the point at once, yes, it could have been an email, and then finds
the one thing the email version could never provide: an audience
watching the host read the email out loud for forty-five minutes.
The humour is in the waste itself, performed live, with a captive
room and a presenter who mistakes reading aloud for leading. Every
word earns its place, because the line is one sentence that moves
from agreement to indictment without stopping. It is the kind of
line that gets a knowing laugh in any office, and it stays well
inside the two hundred character cap. The program holds the line,
checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line joke to `/output/entry.txt`.
